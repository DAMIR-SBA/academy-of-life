# 🎓 Академия Жизни

**Научись жить — играя.** Интерактивный образовательный сайт-игра: 12 факультетов о том, чему не учат в школе.

Каждый факультет: **Урок → Игра → Разбор ошибок → Итоговый тест → «Что ты узнал»**.

## Языки

Русский, узбекский (латиница) и английский — переключатель в шапке сайта.

## Запуск

Сервер не нужен. Скачай репозиторий и открой `index.html` в браузере.

Или включи GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

## Технологии

HTML, CSS, JavaScript без сборки, Three.js (3D), Web Audio API (звуки), Web Speech API (озвучка английского), Canvas. Прогресс хранится в `localStorage`.
